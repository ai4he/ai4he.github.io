# Archived HAIE Lab website (pre-2026 version)

Static snapshot of the original haielab.org site, exactly as GitHub Pages built
it on 2026-10-03 (Jekyll output, no build step needed). Served at
https://haielab.org/old/. Pages carry `noindex` so search engines treat the
current site as canonical. The original Jekyll sources were removed from the
repository root on 2026-10-05, when the redesigned site moved there; they remain
in the git history before that commit.
