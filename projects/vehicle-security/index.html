Resilient Vehicle Network Security

Security architecture for next-generation military ground vehicles.

Through Clemson's Virtual Prototyping of Ground Systems (VIPR-GS) center, funded by the U.S. Army DEVCOM Ground Vehicle Systems Center, this project led by Dr. Pierluigi Pisu develops a resilient network security architecture for next-generation military ground vehicles.
