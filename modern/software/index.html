Fermi-LLM

A web platform that turns a plain-English request into a real Fermi-LAT gamma-ray analysis: it writes the FermiPy configuration and Python driver, checks them, runs exactly what the scientist approves and shows every step. Every model, rule, validator and data source is a pluggable module.

Trust-Calibration Benchmark

A small, auditable qualification test for language models used as workers in human-computation pipelines: 60 yes/no items across five domains with independently audited gold labels, plus the evaluation harness.
