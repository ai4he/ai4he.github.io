Usable Secure Authentication

Making secure authentication usable in everyday life.

Secure authentication only protects people if they can use it. Funded by the NSF Secure and Trustworthy Cyberspace program and led by Dr. Kelly Caine, this project tracks the usability of secure authentication systems. Ph.D. student Christopher Kalahiki contributes to the project, which produced a study of authentication routines among college students presented at HFES ASPIRE 2026.
